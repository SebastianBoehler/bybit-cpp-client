REST v5

Bybit C++ Client

Lightweight REST v5 wrapper in modern C++, mirroring the TS wrapper surface. Split into public/private clients with shared signing and HTTP helpers.

Scope

  • REST endpoints: getQueryApiKey, getAccountInfo, getPositionInfo, getInstrumentsInfo, submitOrder, setLeverage, getHistoricOrders, getFeeRate.
  • Shared auth/signing (HMAC-SHA256) and libcurl transport.
  • Public vs private client separation; facade RestClient retains simple API.

Build

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
cmake --install build --prefix dist

FetchContent usage

include(FetchContent)
FetchContent_Declare(
  bybit_cpp_client
  GIT_REPOSITORY https://github.com/SebastianBoehler/bybit-cpp-client.git
  GIT_TAG main
)
FetchContent_MakeAvailable(bybit_cpp_client)

target_link_libraries(app PRIVATE Bybit::bybit_client)

Minimal example

#include <bybit/rest_client.hpp>
#include <iostream>

int main() {
  bybit::RestClient client{"YOUR_KEY", "YOUR_SECRET", "linear"};
  try {
    auto instruments = client.get_instruments_info();
    std::cout << instruments << "\n";
  } catch (const std::exception& ex) {
    std::cerr << "Error: " << ex.what() << "\n";
  }
}

Env & tests

  • Set BYBIT_API_KEY, BYBIT_API_SECRET, BYBIT_CATEGORY to run readonly test.
  • .env.example provided; .env is gitignored.
  • Run tests: ctest --test-dir build

Style

  • Clang-format hook runs on staged C/C++ files (.git/hooks/pre-commit).
  • Code split into HttpClient, PublicRestClient, PrivateRestClient, facade RestClient.

Roadmap

  • Optional: migrate HMAC to OpenSSL EVP_MAC to silence deprecation warnings.
  • Add websocket support (positions/tickers) after REST parity is solid.
